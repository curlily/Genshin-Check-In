# Genshin Impact Check-In

Automatically claim your daily Genshin Impact login rewards with this simple automation tool.

## Prerequisites
- Genshin Impact account (logged in on the website)
- Web browser
- Windows system

## How to Use

### 1. Get your Auth-Token
- Visit the [Genshin Check-In Website](https://act.hoyolab.com/ys/event/signin-sea-v3/index.html?act_id=e202102251931481) and ensure you're logged in
- Open your browser's Developer Console (F12 or Right-click → Inspect → Console tab)
- Paste the provided code into the console and press Enter

### 2. Save the Downloaded File
- After executing the code, a file will be downloaded
- Move this file to the same folder as `genshin-check-in.exe`

### 3. Run the Automation
- Execute the batch file to claim your reward!

## Optional: Auto-Startup Configuration

To automatically claim rewards each time you start your PC:

1. Create a shortcut to the batch file
2. Move the shortcut to your **Startup folder**:
   - Press `Win + R` and type: `shell:startup`
   - Paste the shortcut there
3. Your rewards will now be claimed automatically on each startup <3
